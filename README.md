# Arpha Programming Language 🚀

Arpha is a work‑in‑progress language influenced by Magpie, C, D, Nemerle, Go, and many others.

## Getting Started 💡

Explore the `samples` directory for small programs and the `testsuites` directory for language tests.

## Development 🛠️

Build and run the test suite:

```bash
cmake -B build
cmake --build build
ctest --test-dir build
```

## Status 📦

Arpha is under active development; expect sharp edges and lots of experimentation.

Have fun exploring! 😄
